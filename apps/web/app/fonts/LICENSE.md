# Bundled fonts

- `Inter-latin-variable.woff2`: Inter (variable, latin subset), by Rasmus Andersson, SIL Open Font License 1.1, https://rsms.me/inter/
- `JetBrainsMono-latin-500.woff2`: JetBrains Mono (weight 500, latin subset), by JetBrains, SIL Open Font License 1.1, https://www.jetbrains.com/lp/mono/

Both were taken from Google Fonts on 2026-10-10 so that `next build` does not need a network connection to Google.
