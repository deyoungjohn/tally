# Token icon sources

One icon per ticker, the same for every issuer, saved as `<TICKER>.png` (128 x 128, transparent, under 10 KB).
The logos identify a company and belong to their owners. Run `pnpm tokens:icons` after adding files: it checks every
file and regenerates `lib/token-icons.generated.ts`, which decides which tickers show a picture.
