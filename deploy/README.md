# Deployment

All deployment instructions for Tally and its workers are in [`docs/deployment.md`](../docs/deployment.md). Nothing else in the repository describes how to deploy or run it; if you find a conflicting instruction elsewhere, delete it and fix that file.

This folder holds `restart.sh` (starts, stops and watches the web server and every worker) and `tally.env.example` (the names of the settings, never values).
