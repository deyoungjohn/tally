## How to connect (applies to every screen)
- Build only from view models in `apps/web/modules/<name>/view-model.ts` (`loadRadar`, `loadFlow`, `loadPortfolio`, `loadStatement`, `loadReceipts`, `loadReceipt`, `loadQuality`). Never edit a view model, a `plain.tsx`, anything under `packages/`, `apps/worker/`, `apps/web/lib/server/engine.ts` or `app/api/modules/**`. If a field is missing, list it in your PR under "View-model requests".
- Server components call the loader inside `<ModuleBoundary module="…">` exactly as the module's `plain.tsx` does (store from `openStore()`, closed in `finally`). A client page that needs data for a wallet reads it through a small route under `apps/web/app/api/vm/<name>/route.ts` that calls the loader on the server and returns the view model as JSON (bigint amounts are already strings). Rate-limit it like the other routes (`rateLimited`, `tooMany`).
- Portfolio, statement, activity and receipts are **public chain data**, so those routes may take a wallet address from the query (validate `^0x[0-9a-fA-F]{40}$`). **Guardian data is private: never take its address from a query, header or body.** See the Guardian slice.
- Every module screen has four designed states: loading, empty (with the view model's `reason`), stale ("last update 4 min ago" from `ageMs`) and degraded (module down). Feature flag off = the entry point and nav item are hidden and the route 404s; read flags from `/api/modules/health` through `useModuleFlags`. Do not touch flag values.
- Amounts are strings of integers (bigint) in 1e18 fixed point: format them with the helpers in `lib/format.ts`, never `Number()` on raw token amounts. Shares are always shown as shares; an unknown multiplier shows "unknown" and the reason, never a 1:1 guess. Fixture or recorded data is labelled as such and never as live.
- Copy states facts, never advice. Follow `DESIGN.md` exactly, re-skin beUI components with our tokens, and check every screen at 375 / 768 / 1280 px and with reduced motion. No contract address anywhere in the UI except `/docs` and transaction links.
- Do not touch the buy path (`use-trade-flow.ts`, `trade-stages*`), ShareGuard, the sell flow logic or `lib/trade-plan/**`. Do not add dependencies without asking.
