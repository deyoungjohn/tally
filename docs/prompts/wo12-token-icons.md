# WO-12 (Sonnet): stock icons everywhere (one icon per ticker)

Existing branch, fetch `main` first, no new branch, fixtures only. Palette rule (no greys). Presentation only: do not touch the buy, sell, Migrate or ShareGuard logic.

## The files
The chief engineer downloads the stock icons from PancakeSwap and saves **one icon per ticker, the same for every issuer** (NVDAon, NVDAB and NVDAx all show the NVDA icon), as `apps/web/public/tokens/<TICKER>.png` (uppercase ticker, for example `NVDA.png`). Spec: square, 128 x 128 px, transparent background, under 10 KB each (the site shows them at 16 to 40 px, so 128 px is sharp at 3x). A PancakeSwap file of 256 px or more is downscaled to 128; keep its shape (circle or square), add no padding or background. Add `apps/web/public/tokens/SOURCES.md` (a table: ticker, where it came from, date; the logos identify a company and belong to their owners). Start with the 21 buyable tickers (`apps/web/lib/tickers.ts`); tokens with no file yet use the fallback.

## Build
1. `scripts/token-icons.mjs` (Node, no new dependency beyond what the repo already has; if an image library is needed use `sharp` only if it is already installed, otherwise do the check without resizing): `pnpm tokens:icons` (a) lists every file in `public/tokens/` and **fails** if one is not 128 x 128, is over 10 KB, is not a PNG or WebP, or is not named like a ticker (`^[A-Z0-9.]{1,10}\.(png|webp)$`); (b) writes `apps/web/lib/token-icons.generated.ts` exporting the set of tickers that have a file. Run it from the web build's prebuild step only if that is a one-line change; otherwise document the command in the PR for the chief engineer.
2. `components/ui/token-icon.tsx`: `<TokenIcon ticker size={16|20|24|32|40} />`. If the ticker is in the generated set, render a plain `<img src="/tokens/TICKER.png" width height alt="" loading="lazy" decoding="async">` with the size fixed (no layout shift); otherwise a **letter fallback**: a circle in faint white with the first letter of the ticker in white (palette tokens, no greys), the same size. If the image still fails to load, switch to the fallback (`onError`). The ticker is read from `ticker` or derived from a token symbol with `tickerOf(symbol)` (strip the issuer suffix `on`, `B`, `x` using the registry's real tokens, not a regex guess). The icon is decorative (`alt=""`); the name next to it is the label.
3. Use it in: the stock picker and Select options (Home card, Trade card, Migrate), the issuer list rows on Trade, Portfolio Holdings rows, Statement rows, the Send token list, and the Pies page and Portfolio suggestion cards if they are on `main`. Sizes: 20 to 24 in lists, 32 to 40 in cards. Do not change any text, order or behaviour.
4. Tests: unit (generated set hit and miss, error fallback, the symbol-to-ticker helper for NVDAon, NVDAB, NVDAx and a ticker ending in B or x), an e2e that the pickers show an icon or the fallback with no failed requests and no horizontal scroll at 375 / 768 / 1280, and that missing files cause no 404 requests (the set decides). `pnpm tokens:icons` has a test with deliberately bad fixtures kept outside `public/`.
5. In the PR, say how many icons are present, the total size, and list the tickers still on the fallback.
